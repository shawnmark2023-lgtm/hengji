# 上线阶段：账户验证与同步路线

## 1. 原则

账户体系不是 MVP 的前置条件。它在本地核心体验稳定、隐私影响评估完成后单独上线，且必须与“消费平台授权”区分：衡记登录只证明用户能访问自己的加密数据；支付宝/微信/电商 OAuth 只授权对应连接器，二者 token、scope 和撤销流程互不复用。

## 2. 目标架构

- 主身份：随机生成的内部 `accountId`，不把手机号/邮箱作为主键。
- 首选登录：Passkey/WebAuthn；Apple 平台可提供 Sign in with Apple 作为可选入口。
- 恢复：恢复码 + 已信任设备；邮箱/手机号仅作为用户主动开启的恢复通道。
- 会话：短期 access token + 可轮换 refresh token，按设备记录并支持远程撤销。
- 设备：首次注册生成设备密钥，私钥保存在 Keychain/Keystore/Credential Locker。
- 同步：原始账本在客户端加密，服务端只保存密文、版本和最少路由元数据。
- 连接器：第三方 OAuth token 使用独立 vault 和独立 consent record，不进入账本同步载荷。

## 3. 分阶段

### Phase A：本地安全

- 生物识别/系统 PIN 解锁本地账本。
- 数据库密钥存入系统安全存储。
- 加密备份、恢复演练和导出提示。

### Phase B：账号与设备

- Passkey 注册/登录、设备清单、会话撤销、恢复码。
- 风险事件提醒：新设备、恢复、连接器新增、批量导出。
- 限流、防重放、CSRF/state/PKCE、审计日志脱敏。

### Phase C：端到端加密同步

- 客户端生成主密钥，使用设备公钥封装。
- 以记录/操作日志同步，避免数据库文件覆盖。
- 冲突策略：金额与关联关系需要显式合并；标签/备注可使用字段级版本。
- 删除传播、密钥轮换、丢失设备撤销和灾难恢复。

### Phase D：平台连接器生产化

- 完成各平台应用主体、合同、scope、回调域名和隐私审查。
- 授权前展示字段、用途、保留期；授权后可随时暂停和删除。
- 定期检查 token 过期、scope 变化和平台条款变更。

## 4. 验收

- 没有账号也能继续使用本地功能。
- 服务器数据库泄露不能直接暴露原始账本。
- 撤销一个设备不会破坏其他设备的数据访问。
- 连接器撤权不影响衡记账号；删除衡记账号会触发连接器 token 删除。
- 恢复流程有防社工设计，不依赖客服读取用户明文数据。
