# 恒迹 P1 交付计划（Windows + Android）

日期：2026-07-27

## 1. 本轮范围

本轮继续沿用 P0 的平台范围：完成 Windows 与 Android 可在当前仓库和 Windows 主机上交付、验证的 P1；iOS/macOS 不进入本轮完成声明。

P1 采用三种状态：

- `DONE_WIN_ANDROID`：Windows/Android 范围已实现，自动化门禁通过。
- `READY_EXTERNAL`：客户端或服务端安全边界已实现，但启用仍依赖商店审批、已签约生产 API、签名账号或代表性真机。
- `DEFERRED_APPLE`：仅由 iOS/macOS 承载的工作，本轮不处理。

## 2. 编号交付清单

1. `DAT-004 / SEC-004`：为受保护账本增加可审计的密钥世代、崩溃安全轮换和显式提交结果；轮换提交失败时旧账本必须保持可读，系统级回滚与密钥丢失灾难演练列为实体设备外部门禁。
2. `UX-009`：Android 提供桌面小组件、启动器快捷记账和系统分享入口；Windows 提供应用内快捷键与冲突提示。所有入口只打开可撤销或可取消的确认界面，不直接写账。
3. `IMP-005`：实现本地 OCR/PDF 导入适配器、输入上限和字段置信度契约；金额、日期、商户等低置信度字段必须经用户确认后才能进入既有导入提交链路。
4. `IMP-006`：获批前不声明 `READ_SMS`/`RECEIVE_SMS`。提供“用户主动分享金融短信文本”的无敏感权限适配路径；非金融文本本地拒绝，不上传、不保留原文。
5. `INS-006`：实现默认关闭的模型解释同意记录、脱敏聚合白名单和撤回即停用。未配置受审提供方时保持离线规则解释，不进行网络外发。
6. `PRI-005`：实现只接受 `OFFICIAL_OR_CONTRACTED_API` 来源的有界缓存，记录来源、币种、成色、运费、观察时间、过期时间和删除结果；不增加抓取器或私有 API。
7. `PRI-006`：实现 Android 通知权限说明和本地后台评估边界。未配置授权行情源时不做后台网络请求，示例/手工报价不得伪装成实时通知。
8. `QA-006`：补齐 20 份脱敏 OCR/文本样本、轮换/恢复、缓存 TTL、同意撤回、分享入口和通知门控测试；运行现有 10 万流水基线与混淆发布构建。

## 3. 外部依赖边界

- Google Play 尚未批准短信权限时，发布清单必须保持零短信读取权限；审批材料与商店审核结果标记为 `READY_EXTERNAL`。
- 没有已签约或官方生产行情 API 时，生产提供方保持 fail-closed；缓存和调度能力可以完成，但不得将沙箱或手工数据标记为实时。
- Android 通知需由用户在系统界面明确授权；自动化只能验证请求时机、拒绝路径和内容脱敏，不能代替用户授权。
- 代表性低端 Android 真机、锁屏、卸载、系统备份/恢复属于设备验收；当前主机可完成模拟器和主机测试，但不冒充真机证据。

## 4. 质量门禁

完成声明至少需要：

1. Kotlin/TypeScript/Python 格式与静态检查通过。
2. 受影响模块单元测试、Android 主机测试、共享 Compose UI 测试通过。
3. Android lint、debug/release APK 与 Desktop 混淆发布构建通过。
4. Android 受保护账本启动/重开设备测试通过。
5. 财务应用专项校验器通过。
6. Windows/Android CycloneDX SBOM、许可证策略与漏洞扫描通过，构建工具和 GitHub Actions 也纳入固定版本门禁。
7. 文档按 `DONE_WIN_ANDROID`、`READY_EXTERNAL`、`DEFERRED_APPLE` 精确更新，不把外部依赖配置写成已验证。
