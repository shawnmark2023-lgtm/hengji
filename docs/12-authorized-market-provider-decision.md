# 授权二手行情源决策包

日期：2026-07-27
状态：`DECISION_REQUIRED`

## 1. 推荐结论

当前继续保持生产行情源关闭，不接抓取器、不接私有接口，也不把沙箱、演示或手工报价标为实时。

若首发市场覆盖 eBay 支持的国际市场，可把 eBay Browse API 作为第一项合同与数据适配性验证候选；它提供可购买中的挂牌商品搜索、成色、价格、币种和部分配送信息，但挂牌价不等于成交价，不能直接表述为二手资产的真实成交估值。eBay Buy APIs 的生产使用面向合作伙伴并需要申请生产访问，获批并无保证。

若首发市场是中国大陆，目前不预选任何供应商。只有平台提供公开官方 API，或项目取得书面授权/聚合合同后，才进入技术接入；用户提供的导入文件和手工报价继续作为默认方案。

## 2. 产品负责人必须确定的输入

| 决策项 | 必填内容 |
| --- | --- |
| 首发地区 | 国家/地区与允许展示的 marketplace |
| 优先品类 | 手机、电脑、摄影、家电、奢侈品等，最多先选 2 类 |
| 价格语义 | 在售挂牌价、已成交价、回收商报价或多源组合 |
| 更新目标 | 例如 24 小时或 7 天；禁止笼统写“实时” |
| 月调用量 | 资产数、每资产候选数、刷新频率和峰值 |
| 商业用途 | 仅估值展示、跳转购买、联盟营销或交易撮合 |
| 数据保留 | 原始响应、规范化报价、来源 URL、删除时限 |
| 预算与合同主体 | 月预算、签约实体、法务/隐私负责人 |

缺少任一项时，生产 provider 保持 fail-closed。

## 3. 候选验证顺序

1. `MANUAL`：现有本机手工报价，继续作为永远可用的离线基线。
2. `OFFICIAL_API`：只评估目标市场的平台官方 API；先做 sandbox/测试数据映射，不在客户端保存 secret。
3. `LICENSED_AGGREGATOR`：官方 API 无法覆盖所需的已成交价、地区或品类时，发起带数据来源和再分发权的合同评估。
4. 无合格候选：保持行情功能为手工/演示模式，不降级到网页抓取、cookie 复用或未公开接口。

## 4. Provider 准入门槛

候选必须同时满足：

- 书面允许当前地区、应用场景、缓存、展示和派生估值；明确是否允许保存来源 URL。
- 能标注 `OFFICIAL_API` 或 `LICENSED_AGGREGATOR`，并提供可审计的 provider 和采集时间。
- 返回规格、成色、币种、商品价和运费；缺失字段必须降低置信度，不能用默认值伪造。
- 支持有界响应、超时、限流、重试退避和删除；生产凭据只留在远端服务的密钥存储中。
- 隐私与合同明确数据保留、删除、分包商、跨境传输、事件通知和终止后的数据处理。
- 数据质量验证覆盖重复商品、异常值、地区/币种错配、模糊规格、过期报价和样本不足。

任一项不满足即拒绝上线。

## 5. eBay Browse API 验证假设

只有在“国际市场 + 在售挂牌价可作为参考区间”成立时才启动此候选：

- 使用应用访问令牌的服务端调用；client secret 和 access token 不进入 Windows/Android 客户端。
- 搜索仅用于候选报价，不把搜索结果排序解释为真实市场价值。
- 仅接受目标 marketplace、同币种、匹配规格和可解释成色的条目；价格与运费分开保存。
- 记录 `itemId`、观测时间、过期时间和允许的来源链接；遵守合同约定的缓存/删除期限。
- UI 固定展示“挂牌参考价”，样本不足或匹配置信度低时只显示范围或提示，禁止单点估值。
- 未取得生产访问、条款审查和数据保护批准前，provider 状态保持禁用。

## 6. 接入前验收清单

- [ ] 产品负责人完成第 2 节输入并签字。
- [ ] 法务确认数据许可、展示、缓存、删除和派生估值权利。
- [ ] 隐私评估列出请求字段、响应字段、保留期和跨境路径。
- [ ] 服务端凭据、域名白名单、限流、超时、日志脱敏和撤销演练通过。
- [ ] sandbox 只显示为非生产，不进入生产缓存。
- [ ] 生产 API 返回的 provenance、币种、成色、运费、采集时间、置信度和 TTL 全部通过契约测试。
- [ ] Provider 停用、合同到期和大规模错误时 fail-closed，不回退到抓取或伪实时数据。
- [ ] 至少一轮人工标注数据集验证匹配精度和价格区间质量，并记录可接受阈值。

完成这些条件之前，`PRI-005` 与 `PRI-006` 继续保持 `READY_EXTERNAL`。
