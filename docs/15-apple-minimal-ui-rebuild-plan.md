## 1. 重建目标

将现有偏卡片化、重填充的界面重建为“内容优先、轻量线条、克制色彩、清晰层级”的跨平台界面。设计语言参考 Apple Human Interface Guidelines 的信息层级、导航、可访问性和渐进披露原则，但不复制 Apple 私有素材或把非 Apple 平台伪装成原生 Apple 应用。

最终界面必须同时满足：

- 交易、资产、洞察和导入能力不退化，已有领域计算与数据来源标识保持真实。
- 手机使用干净、稳定的底部 Dock；Dock 只做顶层导航，不放执行动作。
- “记一笔”是独立主操作，可使用浮动圆形按钮或页面工具栏按钮。
- 首次引导短、可跳过、可重新进入，不阻塞启动，不提前索取非必要权限。
- 默认本地优先、无追踪、无新增网络权限，不用外部字体、远程图片或广告 SDK。
- 同一组件支持亮色、暗色、窄屏、宽屏、200% 字号和键盘操作。

主要设计依据：

## 2. 体验原则

### 2.1 视觉语言

- 大面积使用系统背景和内容留白，用 1 px 视觉分隔线表达结构。
- 减少卡片嵌套、彩色填充、胶囊标签和大面积阴影。
- 只保留一个品牌强调色；金额正负、警告和错误使用语义色。
- 层级主要依靠字号、字重、间距和对齐，不依靠装饰。
- 圆角保持克制：控件 10–14 dp，浮层 18–22 dp；普通列表不强制加外框。
- 图标统一使用中性线性图标，保持相同描边感和视觉尺寸。
- 动画快速、可中断、尊重“减少动态效果”，不为装饰增加长动画。

### 2.2 导航合同

- 手机 Dock 固定 5 个顶层目的地：概览、流水、物品、洞察、设置。
- Dock 在主层级持续可见，进入编辑、导入预览等专注流程时可隐藏。
- Dock 保留各标签页的滚动位置和局部状态。
- “记一笔”不是第六个标签页，也不占用中间导航项。
- 平板和桌面使用紧凑侧栏或导航轨；选择态使用细线、轻色背景或字重变化。
- 页面工具栏只承载搜索、筛选、新建、编辑等命令，不承担顶层导航。

### 2.3 首次引导合同

首次引导控制在 3 步内，并允许随时跳过：

1. **数据只属于你**：解释本地账本、设备加密和默认无网络。
2. **从第一笔开始**：可直接打开“记一笔”，也可继续探索空账本。
3. **导入与备份**：说明导入前预览、备份位置和恢复入口。

约束：

- 引导出现在应用完成启动之后，不把启动页变成长教程。
- 每步提供“跳过”、返回、继续和 `1/3` 进度信息。
- 完成或跳过状态持久化，设置页提供“重新查看新手引导”。
- 不强制创建账户，不诱导开启联网，不在首次启动索取通知或短信权限。
- 若未来加入示例数据，只能写入全新空账本，并永久显示“示例/非真实数据”标识。

## 3. 信息架构与页面目标

### 概览

- 顶部显示当前月份、隐私状态和“记一笔”主操作。
- 首要信息是本月收入、支出、结余；用排版和对齐代替三张重卡片。
- 分类消费使用简洁横条或线性图表，保留可读数字，不只依赖颜色。
- 最近流水和关键洞察各显示少量条目，并提供明确的“查看全部”。

### 流水

- 以日期分组的轻量列表为主，行间用留白或细分隔线。
- 搜索、筛选、导入位于工具栏或底部操作表，不长期占用内容空间。
- 金额、币种、账户和来源的语义保持不变。
- 空状态直接提供“记一笔”和“导入流水”两个下一步。

### 物品

- 以物品名称、当前估值、持有成本和更新时间构成主次层级。
- 沙盒或非实时价格必须持续显示来源与“非实时”标记。
- 明细页用分区列表表达，不堆叠多层卡片。

### 洞察

- 每条建议必须同时展示结论、依据和可执行动作。
- 图表默认简洁，不使用装饰性渐变和无意义动画。
- 反馈控件保持可访问标签，提交失败可以恢复或重试。

### 设置

- 按“账本与安全、导入与备份、外观与辅助功能、关于”分组。
- 本地优先、网络状态、加密状态和数据来源必须可见但不过度警示。
- 提供主题、减少动态效果、新手引导重播和隐私说明入口。

## 5. 推荐实施顺序

1. `UI-002`–`UI-006`：先冻结合同和组件语法。
2. `UI-007`–`UI-013`：完成 Shell、Dock、桌面导航和首次引导。
3. `UI-014`–`UI-020`：逐页迁移，并为每页补齐所有状态。
4. `UI-021`–`UI-024`：统一做可访问性、自动化和工程回归。
5. `UI-025`–`UI-030`：添加动效、视觉基线、性能和真实设备验证。

每完成一个页面就删除对应旧组件引用，不同时长期保留两套主题和两套组件体系。

## 7. 禁止事项

- 不在 UI 层直接读写数据库、文件、网络或平台密钥。
- 不用 `Double` 或格式化字符串替代领域层金额值。
- 不用静态演示数字覆盖真实应用状态。
- 不移除加密、来源、非实时、沙盒、本地优先等必要披露。
- 不新增账户强制、行为追踪、广告、远程字体、密码填充或私有 API。
- 不把 Dock 当作操作栏，不用第六个标签页承载“记一笔”。
- 不把平台未验证项写成已经通过。
